# InternNova Homepage Redesign

An independent homepage redesign concept built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — semantic homepage structure and content
- `style.css` — responsive styling, layout and motion
- `script.js` — mobile navigation, FAQ accordion, program filters, scroll reveal and back-to-top button

## Run locally
Open `index.html` in a browser, or open this folder in VS Code and use the Live Server extension.

## Before submitting
1. Compare the copy and links with the current official InternNova website: https://internnova.co.in/
2. Confirm which program names, services, workshops and benefits are currently offered. Update any illustrative wording accordingly.
3. Test on desktop and mobile; test navigation, program filters and each FAQ.
4. Add your own GitHub repository URL and live deployment URL to your internship submission.

## Deploy with GitHub Pages
1. Create a new GitHub repository, for example `internnova-homepage-redesign`.
2. Upload `index.html`, `style.css`, `script.js` and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for the Pages deployment and open the published URL shown on that page.

## Project note
This is a student-built redesign concept, not the official InternNova website. Program cards are illustrative categories and do not guarantee current openings or benefits. Replace any content that does not match verified information from the official website.
