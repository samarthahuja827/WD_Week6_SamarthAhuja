
# InternNova — Internship Website

## Project Overview
InternNova is a responsive internship website built using HTML, CSS, and JavaScript. It presents internship programs, domains, workshops, testimonials, FAQs, and an application form.

## Objectives
- Build a responsive website for desktop, tablet, and mobile.
- Practice semantic HTML and modern CSS layouts.
- Implement JavaScript interactivity and form validation.
- Use Git and GitHub for version control.
- Deploy the website using GitHub Pages.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Features
- Responsive navigation menu
- Rotating text and animated statistics
- Internship program filtering
- Testimonial slider
- FAQ accordion
- Application form with name, email, domain, and program selection
- Basic client-side form validation

## Project Files
- `index.html` — Website structure
- `style.css` — Styling and responsive layout
- `script.js` — Interactive features and form validation

## How to Run Locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.
